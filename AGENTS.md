# This is NOT the Next.js you know

This version has breaking changes — APIs, conventions, and file structure may all differ from your training data. Read the relevant guide in `node_modules/next/dist/docs/` before writing any code. Heed deprecation notices. 

**STRICT RULES - CODE QUALITY MANDATORY**

1. **NO USELESS COMMENTS** - Remove all comments that don't add significant value. Code should be self-documenting.
2. **NO DUMMY CODE** - No empty placeholders, no `// TODO: implement later` stubs.
3. **REAL IMPLEMENTATION** - If something is needed, implement it properly or remove it entirely.
4. **NO COMMENTED OUT CODE** - Delete commented sections instead of leaving them.
5. **CLEAN CODE** - Keep functions small and focused. Avoid deeply nested structures.
6. **TYPE SAFETY** - Use TypeScript correctly with proper types and interfaces.
7. **Performance** - Optimize where necessary without sacrificing readability.
8. **STRICT FORMATTING** - Follow Prettier/ESLint rules. No lint errors.
9. **NO BAD PRACTICES** - Avoid `any` types, unnecessary type assertions, or hacky workarounds.

**If you cannot implement something properly, remove it.**
